PawTrack Setup Guide

Complete guide to configure RevenueCat, Apple App Store Connect, and Google Play for in-app subscriptions

1
Apple Developer Account

You need an Apple Developer account ($99/year) to publish on the App Store and configure in-app purchases.

Step 1.1

Enroll in Apple Developer Program

If you don't have one yet, enroll at:

https://developer.apple.com/programs/enroll/
⚠️ Approval can take 24-48 hours. You need this before configuring subscriptions.
Step 1.2

Create App ID in App Store Connect

https://appstoreconnect.apple.com/apps
  1. Click "+" → "New App"
  2. Platform: iOS
  3. Name: PawTrack
  4. Primary Language: English (U.S.)
  5. Bundle ID: com.matheuspegoraro.pawtrack
  6. SKU: pawtrack-ios
  7. Click Create
Prompt for AI — App Store Description
Write an App Store description for "PawTrack" — a mobile app that helps pet owners track their pet's health records (vaccines, medications, vet visits, weight) and get smart reminders for upcoming health events. Target audience: US pet parents, 25-45 years old, who treat their pets like family. Requirements: - Short description (max 30 characters): for the subtitle field - Full description (max 4000 characters): engaging, benefit-focused, with clear feature list - Keywords (max 100 characters, comma-separated): for ASO optimization - Promotional text (max 170 characters): for the promotional text field - 3 key phrases for screenshots captions Tone: warm, trustworthy, caring — not clinical or childish. Mention: vaccines, medications, vet visits, reminders, PDF export, family sharing. Price model: Free with premium subscription ($5.99/mo or $49.99/yr).
Step 1.3

Generate In-App Purchase Key (P8)

https://appstoreconnect.apple.com/access/integrations/api/subs
  1. Go to Users and Access → Integrations → In-App Purchase
  2. Click "Generate In-App Purchase Key"
  3. Name: PawTrack RevenueCat
  4. Click Generate
  5. Download the .p8 file — you can only download it ONCE
  6. Note the Key ID and your Issuer ID (shown at the top)
⚠️ Save the .p8 file safely. Apple only lets you download it once. You'll upload it to RevenueCat.
2
Create Subscriptions in App Store Connect

Configure the actual subscription products that users will purchase.

Step 2.1

Create Subscription Group

In your app on App Store Connect:

  1. Go to your app → Subscriptions (left sidebar)
  2. Click "+" next to "Subscription Groups"
  3. Group name: PawTrack Pro
  4. Click Create
Step 2.2

Create Monthly Subscription

Inside the "PawTrack Pro" group:

  1. Click "+" next to the group name
  2. Reference Name: PawTrack Pro Monthly
  3. Product ID: pawtrack_pro_monthly
  4. Click Create

Then configure:

FieldValue
Subscription Duration1 Month
Price$5.99
Free Trial7 Days (Introductory Offer → Free → 7 days)
Display NamePawTrack Pro
DescriptionUnlimited pets, smart reminders, PDF export, family sharing

Create Annual Subscription

3
Configure RevenueCat

Connect RevenueCat to your App Store products.

Step 3.1

Upload the P8 Key

https://app.revenuecat.com
  1. Go to your PawTrack project → Apps → your Apple app
  2. Under "In-App Purchase Key Configuration":
  3. Upload the .p8 file from Step 1.3
  4. Enter the Key ID
  5. Enter the Issuer ID
  6. Enter your App Bundle ID: com.matheuspegoraro.pawtrack
  7. Click Save
Step 3.2

Create Products in RevenueCat

  1. Go to Products (left sidebar)
  2. Click "+ New"
  3. Add product:
    • Identifier: pawtrack_pro_monthly
    • App: your Apple app
  4. Add another product:
    • Identifier: pawtrack_pro_annual
    • App: your Apple app
💡 The product identifiers must match exactly what you created in App Store Connect (Step 2.2 and 2.3).
Step 3.3

Create Entitlement

  1. Go to Entitlements (left sidebar)
  2. Click "+ New"
  3. Identifier: pro
  4. Description: PawTrack Pro access
  5. Click Create
  6. Attach both products to this entitlement:
    • pawtrack_pro_monthly
    • pawtrack_pro_annual
✅ The app code checks for the entitlement pro — this must match exactly.
Step 3.4

Create Offering

  1. Go to Offerings (left sidebar)
  2. Click "+ New"
  3. Identifier: default
  4. Description: Default offering
  5. Click Create
  6. Add two packages inside this offering:
    • Package: $rc_monthly → Product: pawtrack_pro_monthly
    • Package: $rc_annual → Product: pawtrack_pro_annual
  7. Make sure this offering is set as "Current"
Step 3.5

Enable App Store Server Notifications

  1. In RevenueCat, go to your Apple app settings
  2. Copy the Apple Server Notification URL that RevenueCat provides
  3. Go to App Store Connect → your app → App Information
  4. Scroll to "App Store Server Notifications"
  5. For Production URL, paste the RevenueCat URL
  6. For Sandbox URL, paste the same RevenueCat URL
  7. Version: Version 2
  8. Click Save
💡 This allows Apple to notify RevenueCat of subscription changes (renewals, cancellations, refunds) in real-time.
4
Testing Subscriptions

Test the purchase flow before submitting to the App Store.

Step 4.1

Create Sandbox Tester

https://appstoreconnect.apple.com/access/testers/sandbox
  1. Click "+" to add a new sandbox tester
  2. Use a real email address you have access to (not your main Apple ID)
  3. Fill in name, password, region: United States
  4. Click Create
Step 4.2

Test on Device

  1. On your iPhone: Settings → App Store → Sandbox Account
  2. Sign in with the sandbox tester email
  3. Build and run the app on your device
  4. Go to the Premium screen and try purchasing
  5. Sandbox purchases are free and auto-renew every few minutes
✅ In sandbox, subscriptions renew at accelerated rates: monthly = every 5 minutes, annual = every hour.

Google Play Store (Optional)

Step 6.1

Google Play Console Setup

https://play.google.com/console
  1. Create a developer account ($25 one-time fee)
  2. Create a new app → Name: PawTrack
  3. Go to Monetize → Products → Subscriptions
  4. Create subscription:
    • Product ID: pawtrack_pro_monthly — $5.99/month
    • Product ID: pawtrack_pro_annual — $49.99/year
  5. In RevenueCat: add a Google Play app with your package name and upload the Google Play Service Credentials JSON
💡 For Google Play credentials, follow: RevenueCat Google Play Setup Guide
